# AI 부트캠프 학습 기록

AI 부트캠프 중급 과정을 진행하며 배운 내용을 정리하는 저장소입니다.
데이터 분석부터 머신러닝, 신경망까지 이어지는 커리큘럼을 따라가며,
매 실습을 코드와 함께 기록하고 있습니다.

## 배우는 내용

- **데이터 분석**: pandas를 활용한 데이터 처리
- **데이터 시각화**: Streamlit, Plotly를 이용한 대시보드 구성
- **머신러닝 (회귀)**: 선형/다항 회귀, 경사하강법, 규제(Ridge/Lasso), 평가 지표(MSE, R² 등)
- **머신러닝 (분류)**: 로지스틱 회귀, SVM, 의사결정나무, 퍼셉트론
- **신경망 기초**: 레이어와 뉴런 구조 등 딥러닝 입문 개념

## 사용 도구

- **학습 플랫폼**: Elice, Google Colab
- **로컬 개발환경**: VS Code (Windows)
- **주요 라이브러리**: pandas, NumPy, scikit-learn, Streamlit, Plotly, matplotlib
- **배포/버전관리**: GitHub, Streamlit Cloud

## 저장소 구조

```
├── daily-log/       학습일지 (날짜별 기록)
└── projects/        실습을 정리한 프로젝트들
```
