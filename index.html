Lab 01

Ridge / Lasso / ElasticNet — 규제 회귀

과적합을 막기 위해 손실함수에 벌점을 더하는 세 가지 방법을 비교합니다.

개념 정리

일반 선형회귀는 오차만 줄이려 하다 보니 계수가 지나치게 커지며 과적합될 수 있습니다. 여기에 계수 크기에 대한 벌점을 더하면, 모델이 오차를 줄이는 동시에 계수를 적당히 억제하게 됩니다.

  • Ridge (L2) — 계수의 제곱합에 벌점 → 계수가 작아지지만 0은 되지 않음
  • Lasso (L1) — 계수의 절댓값합에 벌점 → 일부 계수가 정확히 0이 되어 변수가 자동 제거됨
  • ElasticNet — L1과 L2를 l1_ratio 비율로 혼합

핵심 코드

essential 
from sklearn.linear_model import Ridge, Lasso, ElasticNet

ridge = Ridge(alpha=10).fit(X, y)
lasso = Lasso(alpha=10).fit(X, y)
elastic = ElasticNet(alpha=0.01, l1_ratio=0.5).fit(X, y)

FAQ

왜 Lasso만 계수를 정확히 0으로 만드나요?
규제 영역을 기하학적으로 그리면 Ridge는 원형, Lasso는 마름모(다이아몬드) 모양입니다. 마름모는 축 위에 뾰족한 꼭짓점이 있어서, 손실함수의 등고선이 이 꼭짓점에 닿을 확률이 높습니다. 꼭짓점에 닿는다는 것은 한 축의 값(=계수)이 정확히 0이라는 뜻입니다.
alpha와 l1_ratio를 조정하면 성능이 무한정 좋아지나요?
아니요. 규제는 과적합을 막는 도구일 뿐, 모델을 더 똑똑하게 만들지는 않습니다. alpha를 0에 가깝게 줄이면 결국 일반 선형회귀(OLS)에 수렴하며, 그 값이 사실상 상한선입니다. 이 상한선을 넘으려면 다항 특성 추가나 다른 모델이 필요합니다.
메모. 규제 계열 모델은 변수마다 스케일이 다르면 벌점이 불공평하게 적용됩니다. StandardScaler로 스케일링 후 학습하는 것이 원칙입니다.
Lab 02

회귀 평가지표 — RSS, MSE, MAE, R²

모델이 얼마나 잘 맞췄는지를 재는 네 가지 잣대.

개념 정리

네 지표 모두 "실제값 - 예측값"에서 출발하지만, 그 오차를 어떻게 요약하느냐가 다릅니다.

  • RSS — 오차 제곱의 총합 (평균 아님)
  • MSE — RSS를 n으로 나눈 평균, 큰 오차에 민감
  • MAE — 오차 절댓값의 평균, 이상치에 상대적으로 둔감
  • R² — 1 - (RSS / TSS), 평균으로 찍는 것 대비 얼마나 잘 설명하는지 (0~1)

핵심 코드

essential 
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

MSE = mean_squared_error(test_y, predicted)
MAE = mean_absolute_error(test_y, predicted)
R2  = r2_score(test_y, predicted)   # 실제값, 예측값 순서

FAQ

RSS와 MSE는 뭐가 다른가요?
계산 방식은 똑같이 오차를 제곱해서 더하지만, RSS는 총합 그대로, MSE는 거기서 데이터 개수(n)로 나눈 평균입니다. 함수 이름에 "mean"이 들어있으면 나눈 것이라고 기억하면 헷갈리지 않습니다.
R²가 0.75면 좋은 건가요?
특정 숫자가 "정답"인 건 아닙니다. R²는 1에 가까울수록 좋다는 원칙만 있고, 좋은 기준은 분야마다 다릅니다. 노이즈가 많은 현실 데이터(집값 등)는 0.6~0.8도 준수한 편입니다.
Lab 03

퍼셉트론 분류 — Iris 데이터

가장 단순한 형태의 인공 뉴런으로 붓꽃 품종을 분류합니다.

개념 정리

퍼셉트론은 입력값에 가중치를 곱하고 더한 뒤, 기준선을 넘는지에 따라 클래스를 나누는 가장 단순한 신경망 단위입니다. 다만 직선(선형 경계)으로만 데이터를 나눌 수 있다는 한계가 있습니다.

  • 학습률(eta0)이 너무 크면 최적점 근처에서 발산하듯 튕김
  • 입력 특성의 스케일이 다르면 학습이 불안정해짐 → 스케일링 필요
  • 클래스 간 경계가 겹치면 100% 분류는 원천적으로 불가능

핵심 코드

essential 
from sklearn.linear_model import Perceptron
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X_train)
model = Perceptron(max_iter=1000, eta0=0.1, random_state=0)
model.fit(X_scaled, Y_train)

FAQ

정확도를 90%까지 올리려면 뭘 먼저 봐야 하나요?
순서대로 시도하는 게 효율적입니다. 1) 학습률(eta0)을 0.1 근처로 낮추기 2) 특성 4개를 전부 사용하기 3) StandardScaler로 스케일링하기. 그래도 부족하면 클래스 간 경계가 실제로 겹쳐 있어서 선형 모델의 한계일 수 있습니다.
Lab 04

신경망 기초 — TensorFlow / Keras

단일 퍼셉트론의 한계를 넘어, 레이어를 쌓아 비선형 문제를 표현합니다.

개념 정리

단순 신경망(퍼셉트론 1개)은 선형 관계만 표현할 수 있습니다. 레이어를 여러 개 쌓고 활성화 함수로 비선형성을 더하면, 훨씬 복잡한 패턴도 학습할 수 있는 심층 신경망이 됩니다.

  • ReLU — 은닉층에서 흔히 사용, 음수는 0, 양수는 그대로
  • Sigmoid — 이진 분류 출력층에서 사용
  • Softmax — 3개 이상 다중 분류 출력층에서 사용, 확률 합이 1
  • batch_size가 작을수록 한 epoch 내 가중치 업데이트 횟수가 늘어남

핵심 코드

essential 
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(5, input_shape=[2], activation="relu"),
    Dense(5, activation="relu"),
    Dense(3, activation="softmax"),
])
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=["accuracy"])
model.fit(X, y, epochs=100)

FAQ

loss와 metrics는 어떻게 다른가요?
loss는 모델이 실제로 최소화하려고 학습(가중치 업데이트)하는 목표값이고, metrics는 사람이 보기 편하라고 화면에 같이 출력해주는 참고 지표입니다. metrics 값은 학습 방향에 영향을 주지 않습니다.
