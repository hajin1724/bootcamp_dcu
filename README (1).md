# Linear Regression from Scratch (경사하강법 직접 구현)

> AI 부트캠프 중급 과정 학습 기록의 일부입니다. pandas 데이터 분석 → 시각화 → 회귀/분류 ML → 신경망 기초로 이어지는 커리큘럼을 따라가며, 각 실습을 정리·재구현하고 있습니다.

## 개요
scikit-learn 같은 라이브러리를 쓰지 않고, **경사하강법(Gradient Descent)**을 직접 구현해서
선형회귀 모델을 학습시킨 프로젝트입니다. 회귀식의 파라미터(절편, 기울기)가
어떻게 반복 학습을 통해 최적값으로 수렴하는지 이해하는 데 목적을 뒀습니다.

## 무엇을 배웠는가
- **MSE(평균제곱오차)**를 loss 함수로 사용해 예측값과 실제값의 차이를 정량화하는 방법
- MSE를 각 파라미터(beta_0, beta_1)로 미분해 **그래디언트를 직접 유도하고 구현**
- 학습률(learning rate)과 반복 횟수(iteration)가 수렴 속도·안정성에 미치는 영향
- 파라미터별로 그래디언트 크기가 다르면 수렴 속도도 달라진다는 점
  (이 프로젝트에서는 절편 beta_0이 기울기 beta_1보다 훨씬 느리게 수렴하는 현상을 직접 관찰함)

## 구현 방식
1. `prediction()` — 현재 파라미터로 예측값 계산 (`y_pred = beta_0 + beta_1 * X`)
2. `update_beta()` — MSE의 그래디언트를 계산해 파라미터 업데이트 값 산출
3. `gradient_descent()` — 지정한 횟수만큼 반복하며 파라미터를 업데이트
4. 100번 학습마다 회귀선이 데이터에 맞춰지는 과정을 시각화

- 개선 후: iteration을 늘리고 나니 절편도 정상적으로 수렴, 데이터 중앙을 관통하는 회귀선 획득

## 트러블슈팅 기록
- **문제**: 회귀선이 데이터와 어긋나 보임 (절편이 너무 낮게 나옴)
- **원인 분석**: `delta_1`은 X값이 곱해져 그래디언트가 크고, `delta_0`은 그렇지 않아
  상대적으로 느리게 수렴함
- **해결**: iteration 수를 늘리거나, 학습률 조정, 또는 입력값 정규화(scaling) 적용
