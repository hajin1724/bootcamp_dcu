Lab 01

GET vs POST

같은 경로라도 메서드가 다르면 별개의 엔드포인트로 취급된다.

개념 정리

  • GET — 데이터 조회, URL(쿼리스트링)에 값이 실림, 캐싱 가능, 새로고침해도 안전
  • POST — 데이터 생성/전송, body에 데이터가 담김, 보통 서버 상태를 변경함
  • 같은 경로(/echo)라도 GET/POST 데코레이터가 다르면 별개 엔드포인트로 등록됨

핵심 코드

essential 
@app.post("/echo")
def echo_post():
    return {"message": "POST 요청을 받았습니다."}

@app.get("/echo")
def echo_get():
    return {"message": "GET 요청을 받았습니다."}

FAQ

함수 이름이 같아도 라우팅이 되나요?
FastAPI 라우팅 자체는 데코레이터(@app.get, @app.post)로 등록되기 때문에 문제없이 작동하는 것처럼 보입니다. 하지만 파이썬은 같은 이름의 함수가 정의되면 나중 것이 앞의 것을 덮어쓰기 때문에, 다른 곳에서 그 함수 이름을 직접 호출하려던 코드가 있다면 원본 함수가 사라져서 예상 못한 에러가 날 수 있습니다.
실전 버그. 헬퍼 함수 process_text(text, mode)와 엔드포인트 함수 이름이 똑같이 process_text로 겹쳐서, 나중에 정의된 엔드포인트 함수가 원본 헬퍼 함수를 덮어써버렸다. 그 결과 인자 개수가 안 맞아 TypeError → 500 에러로 이어졌다. 함수 이름은 겹치지 않게 짓는 습관이 필요하다.
Lab 02

Path Parameter vs Query Parameter

URL 안에 값이 있느냐, ?뒤에 붙느냐의 차이.

개념 정리

  • Path Parameter — /items/{item_id}처럼 경로 안에 값 위치, 리소스를 식별할 때 사용, 항상 필수
  • Query Parameter — /search?keyword=fastapi처럼 ?뒤에 위치, 검색/필터/옵션에 사용, 기본값 있으면 생략 가능
  • 함수 인자가 경로의 {}에 없으면 자동으로 Query Parameter로 인식됨

핵심 코드

essential 
@app.get("/users/{user_id}/posts")
def get_user_posts(user_id: int, limit: int = 10):
    return {"user_id": user_id, "limit": limit}

# 요청: /users/3/posts?limit=5
# user_id=3 (Path), limit=5 (Query)

FAQ

/users/3/10 처럼 바로 숫자를 붙이면 왜 안 되나요?
경로 정의 자체가 /users/{user_id}/posts이기 때문에, posts라는 고정 문자열이 경로 중간에 반드시 있어야 매칭됩니다. limit은 경로에 없는 값이라 쿼리 파라미터로 취급되므로 ?limit= 형태로 따로 붙여야 합니다.
고정 문자열 posts는 왜 필요한가요?
URL 경로 자체가 어떤 자원을 다루는지 설명하도록 짓는 REST 관습입니다. /users/3/posts는 "3번 유저의 게시글들"이라는 의미를 URL만 보고 알 수 있게 해줍니다. 고정 문자열이 없으면 두 번째 값이 게시글 개수인지 페이지 번호인지 알 수 없습니다.
Lab 03

Request Model / Response Model (Pydantic)

들어오는 데이터는 검증하고, 나가는 데이터는 형식을 제한한다.

개념 정리

Pydantic의 BaseModel을 상속받아 클래스를 만들면, FastAPI가 요청 body를 자동으로 파싱하고 타입을 검증해준다. Request Model은 클라이언트 → 서버로 들어오는 데이터 형식을, Response Model은 서버 → 클라이언트로 나가는 데이터 형식을 정의한다.

  • 타입이 안 맞으면 자동으로 변환 시도 (예: "5" → 5), 변환 불가능하면 422 에러
  • response_model을 지정하면 함수가 뭘 리턴하든 정의된 필드만 걸러서 응답
  • 민감하거나 불필요한 필드를 응답에서 자동으로 숨길 수 있음

핵심 코드

essential 
class ChatRequest(BaseModel):
    message: str

class ChatResponse(BaseModel):
    answer: str

@app.post("/chat", response_model=ChatResponse)
def chat(req: ChatRequest):
    response = call_llm(req.message)
    reply_text = response.choices[0].message.content
    return ChatResponse(answer=reply_text)

FAQ

response_model에 없는 필드로 반환하면 어떻게 되나요?
ChatResponse(reply=..., model=...)처럼 모델에 정의 안 된 필드명으로 반환하려 하면 ValidationError가 발생해 500 에러로 이어집니다. 모델 필드명(answer)과 실제 반환 시 키워드 인자 이름을 정확히 맞춰야 합니다.
Lab 04

실전 에러 디버깅 기록

오늘 만난 에러들과 원인, 해결 과정.

개념 정리

  • 405 Method Not Allowed — POST로 등록된 엔드포인트에 GET으로 요청하는 등 메서드 불일치
  • 422 Unprocessable Entity — 필수 필드 누락, 또는 변환 불가능한 타입
  • 500 Internal Server Error — 서버 코드 내부에서 예외 발생, Swagger UI만으로는 원인 파악 불가 → 터미널 로그 확인 필수

핵심 코드

essential 
# 500 에러 원인 1: temperature 미지원 모델
# openai.BadRequestError: Unsupported value: 'temperature'
# → gpt-5-mini 등 일부 모델은 기본값(1) 외 temperature 미지원

completion = client.chat.completions.create(
    model=MODEL_NAME,
    messages=[...],
    temperature=1,   # 커스텀 값 대신 기본값 사용
)

FAQ

500 에러의 정확한 원인은 어디서 확인하나요?
Swagger UI(/docs)는 "Internal Server Error"라고만 보여주고 구체적인 이유는 안 알려줍니다. uvicorn을 실행 중인 터미널 창에 Traceback 전체가 출력되므로, 거기서 마지막 줄의 에러 메시지를 확인해야 정확한 원인을 알 수 있습니다.
모듈 최상단에 테스트 호출 코드를 두면 왜 위험한가요?
uvicorn이 파일을 import하는 순간 모듈 최상단 코드가 즉시 실행됩니다. 그 안에서 API 호출 같은 코드가 실패하면 서버 자체가 뜨지 못하고 죽어버립니다. 테스트용 호출은 if __name__ == "__main__": 블록 안에 넣어서, 직접 실행할 때만 동작하게 하는 것이 안전합니다.
메모. 지금까지 만든 것은 화면(HTML)이 아니라 JSON 데이터를 주고받는 API 서버다. 브라우저에서 채팅하듯 쓰려면 Swagger UI(/docs)의 Try it out을 쓰거나, 별도의 HTML+JS 프론트엔드를 만들어 fetch로 연결해야 한다.
Lab 05

개발 환경 이슈

Windows + PowerShell + conda + venv 환경에서 겪은 문제들.

개념 정리

  • PowerShell은 보안상 기본적으로 .ps1 스크립트 실행을 막아둠 → conda-hook.ps1 로드 실패의 원인
  • Set-ExecutionPolicy RemoteSigned -Scope CurrentUser로 현재 사용자 한정 실행 정책 완화
  • 가상환경은 만든 위치 폴더에서 .venv\Scripts\Activate.ps1(PowerShell) 또는 activate.bat(cmd)로 진입

핵심 코드

essential 
# 실행 정책 완화 (관리자 권한 PowerShell)
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

# 가상환경 생성 및 진입
python -m venv .venv
.venv\Scripts\Activate.ps1

# 패키지 설치
pip install fastapi uvicorn openai python-dotenv requests

FAQ

ModuleNotFoundError / NameError는 왜 뜨나요?
라이브러리를 쓰려면 1) pip install로 설치 2) import로 이름을 불러오기, 이 두 단계가 모두 필요합니다. 둘 중 하나라도 빠지면 ModuleNotFoundError(설치 안 됨) 또는 NameError(import 안 함)가 발생합니다.
